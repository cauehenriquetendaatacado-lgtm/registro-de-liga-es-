API PRÓPRIA DE REGISTRO DE LIGAÇÕES (sem 3CX, sem Supabase)
==========================================================
Rodar (PC ou servidor da rede, Node.js 22.13 ou mais novo):
    set TOKEN=suasenha        (Windows)   |   TOKEN=suasenha npm start   (Linux)
    npm install   (só se for usar Supabase; para SQLite não precisa)
    node server.js
Painel: http://IP_DO_SERVIDOR:8090/   (digite a senha)
Banco: arquivo dados/ligacoes.db (SQLite). Faça cópia dessa pasta para backup. Pode mudar a pasta com DATA_DIR.
Não defina CX_URL/CX_CLIENT_ID/CX_SECRET: sem elas o 3CX fica desligado e vale o ips.txt.
Com DATABASE_URL definida, usa Postgres/Supabase no lugar do SQLite (no Render grátis o disco é apagado, use isso lá).

COMO AS LIGAÇÕES SÃO REGISTRADAS
1) Telefone Yealink (Features > Action URL) chama a API a cada evento. Direto no servidor:
   http://IP_DO_SERVIDOR:8090/evento?t=SENHA&ip=$ip&evento=incoming&remoto=$remote&callid=$call_id
   (incoming, outgoing, established, terminated, missed). Ou via relay.js como antes.
2) Qualquer sistema seu pode enviar por JSON:
   POST /api/ligacoes   {"ramal":"10.1.99.91","direcao":"entrada","numero":"1199","inicio":"2026-11-09T10:00:00-03:00","duracaoSeg":75}
   (aceita lista; "chave" opcional evita duplicar ao reenviar; status é deduzido se omitido)
   POST /api/eventos    {"ip":"10.1.99.91","evento":"incoming","remoto":"1199","callid":"abc"}

CONSULTAR (senha em ?t=, Authorization: Bearer ou X-API-Key)
   GET /api/ligacoes?de=2026-11-01&ate=2026-11-09&ramal=10.1.99.91&status=atendida|nao_atendida|feita
                    &direcao=entrada|saida&q=numero&pagina=1&limite=50
   GET /api/resumo, /api/ramais, /api/ativas, /ligacoes.csv, /api/ajuda
   DELETE /api/ligacoes/ID
Ramais/telefones permitidos ficam em ips.txt. Fuso: America/Sao_Paulo.
