REGISTRO DE LIGAÇÕES YEALINK - RENDER + SUPABASE
============================================

1) SUPABASE (banco)
   - Crie o projeto em supabase.com e anote a senha do banco que você definir.
   - Clique em "Connect" (topo da tela do projeto) > aba "Connection string" / "Session pooler".
   - Copie a string do SESSION POOLER (host aws-0-...pooler.supabase.com, porta 5432).
     Troque [YOUR-PASSWORD] pela senha do banco.
     IMPORTANTE: use o pooler e não a "Direct connection": a conexão direta do plano grátis só
     funciona em IPv6 e o Render usa IPv4, então daria erro de conexão.
   - As tabelas são criadas sozinhas na primeira vez que o servidor sobe (já com RLS ligado,
     para ninguém acessar os dados pela API pública do Supabase).
   - Para ver os dados: Supabase > Table Editor > tabelas "ligacoes" e "eventos".

2) GITHUB + RENDER
   - Suba esta pasta num repositório no GitHub.
   - Render > New > Web Service > escolha o repositório.
       Build Command: npm install
       Start Command: npm start
   - Em Environment, crie:
       DATABASE_URL = (a connection string do Supabase, Session pooler)
       TOKEN        = uma senha qualquer sem espaços, ex: Tenda2026xyz
   - No log deve aparecer: "Armazenamento: Supabase/Postgres".
   - O Render dá um endereço, ex: https://ligacoes-tenda.onrender.com  (use no lugar de SEU_ENDERECO)

3) IMPORTANTE - IMPEDIR O RENDER DE "DORMIR"
   No plano grátis o Render dorme após ~15 min sem acesso e demora cerca de 1 minuto para acordar.
   Nesse tempo os avisos dos telefones se perdem. Soluções:
   - Plano pago do Render (mais seguro), ou
   - Serviço grátis de "ping" (ex: UptimeRobot) chamando a cada 5 min:
       https://SEU_ENDERECO/saude

4) CONFIGURAR CADA TELEFONE (interface web do telefone: Features > Action URL)
   Troque SEU_ENDERECO e SUA_SENHA (o TOKEN):

   Incoming Call    https://SEU_ENDERECO/evento?t=SUA_SENHA&ip=$ip&evento=incoming&remoto=$remote&callid=$call_id
   Outgoing Call    https://SEU_ENDERECO/evento?t=SUA_SENHA&ip=$ip&evento=outgoing&remoto=$remote&callid=$call_id
   Call Established https://SEU_ENDERECO/evento?t=SUA_SENHA&ip=$ip&evento=established&remoto=$remote&callid=$call_id
   Call Terminated  https://SEU_ENDERECO/evento?t=SUA_SENHA&ip=$ip&evento=terminated&remoto=$remote&callid=$call_id
   Missed Call      https://SEU_ENDERECO/evento?t=SUA_SENHA&ip=$ip&evento=missed&remoto=$remote&callid=$call_id

   Se existir "Reject Incoming Call": use evento=rejected.
   ATENÇÃO: o Render só atende em HTTPS. Alguns Yealink/firmwares só aceitam http:// nesse campo.
   Se o telefone não registrar nada, teste abrindo a URL de um evento no navegador de um computador
   da rede (deve responder "ok") e me avise qual modelo/firmware, que eu ajusto.

5) PAINEL (INSTALÁVEL NO COMPUTADOR E NO CELULAR)
   - Abra https://SEU_ENDERECO no navegador e digite a senha (o TOKEN). Ela fica salva no aparelho.
   - Aparece o botão "Instalar aplicativo":
       Computador (Chrome/Edge): clique no botão (ou no ícone de instalar na barra de endereço).
                                 O painel vira um ícone na área de trabalho.
       Android (Chrome): toque no botão "Instalar aplicativo".
       iPhone (Safari): Compartilhar > "Adicionar à Tela de Início".
   - Mostra por telefone: ATENDIDAS, NÃO ATENDIDAS e FEITAS, taxa de atendimento, últimas ligações,
     filtros (Hoje, 7 dias, Este mês, Tudo ou datas) e download em Excel.
   - No rodapé aparece "Banco de dados: Supabase/Postgres" quando a conexão com o Supabase está funcionando.

   Opcional: o arquivo render.yaml permite criar o serviço no Render com New > Blueprint.

COMO CONTA
   Feita: o telefone discou. Atendida: tocou e atenderam. Não atendida: tocou e ninguém atendeu.
   Só entram os IPs listados em ips.txt (edite no GitHub e o Render atualiza sozinho).

============================================
MODO 3CX (sem Action URL, lê direto do 3CX)
============================================
1) No 3CX (Admin > Integrações > API) o administrador cria uma chave de API e copia
   o Client ID e o Secret (o Secret aparece uma vez só).
2) No Render > Environment, crie:
       CX_URL        = https://tendaatacado.3cx.com.br:5001
       CX_CLIENT_ID  = (o Client ID)
       CX_SECRET     = (o Secret)
   Com as 3 preenchidas, o painel usa o 3CX e a lista de ramais vem do arquivo ramais.txt.
3) Para conferir a ligação, abra:  https://SEU_ENDERECO/api/3cx-teste?t=SUA_SENHA
   Deve mostrar "ok": true e o número de chamadas das últimas 24h.

4) HISTÓRICO POR RAMAL (grava no Supabase)
   Com o modo 3CX ligado e o DATABASE_URL preenchido, o servidor busca sozinho no 3CX as chamadas
   dos ramais de ramais.txt (a cada 2 minutos) e grava/atualiza na tabela "ligacoes" do Supabase
   (origem = 3cx). O painel passa a ler o histórico do banco e não repete chamadas já gravadas.
   - Na primeira vez busca os últimos 30 dias; depois continua de onde parou.
   - Para buscar um período maior de uma vez (opcional):
         https://SEU_ENDERECO/api/3cx-sincronizar?t=SUA_SENHA&dias=90
   - No painel, clique em um ramal para ver o histórico completo dele (até 500 ligações do período);
     "Baixar todas as ligações" baixa só daquele ramal enquanto ele estiver selecionado.
   - Variáveis opcionais no Render: CX_SYNC_MIN (minutos entre atualizações, padrão 2) e
     CX_DIAS_INICIAL (dias buscados na primeira vez, padrão 30).
   - No rodapé do painel aparece "histórico dos ramais atualizado em ...".
